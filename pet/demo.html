Hollowzinho.

Um Hollow de estimação num web component só: sem dependências, arte em SVG e uma API pequena. Ele olha para o cursor, aceita carinho, come, dorme e dispara um Cero.

Experimente

O bichinho está no canto da tela. Passe o mouse nele, clique, segure para carregar um Cero ou arraste para outro canto. Abaixo, a mesma coisa pela API.

    Como usar

    <!-- um arquivo, nenhuma dependência -->
<script src="hollow-pet.js"></script>
<hollow-pet corner="br" lang="pt"></hollow-pet>

// e a API
const pet = document.querySelector("hollow-pet");
pet.feed();
pet.mood("worried", "Opa… deu erro.");
pet.look(0.8, -0.4);              // olha para cima e para a direita
pet.addEventListener("hollow-pet:state", (e) => save(e.detail));
pet.restore(saved);                    // devolve o que foi guardado

    API

    AtributoO que faz
    cornerbr (padrão), bl, tr ou tl. O canto salvo vale mais.
    size, marginTamanho e margem em pixels. Sem size, o pet se ajusta à janela.
    name, lang, tintNome, idioma dos balões (pt ou en) e cor (reishi, ouro).
    inline, staticFica onde está no texto, sem fixar na tela, e sem vida própria.
    no-persist, storage-key, no-helloGuarda o estado em outro lugar, em outra chave ou sem cumprimentar.
    chatter, sleep-afterQuanto fala sozinho (off, low, normal) e quantos segundos até dormir.
    MétodoO que faz
    pet() feed() sleep() wake()As quatro ações do dia a dia.
    cero({x, y, power}) aim()Dispara o Cero num ponto, ou abre a mira para você escolher.
    say(texto, ms) dock(canto)Fala no balão e muda de canto.
    look(x, y, ms)Olha para um ponto (-1 a 1) em vez de seguir o cursor.
    mood(humor, texto)happy, excited, worried, sad ou calm.
    celebrate(texto) nibble(n)Comemora com um Cero para cima; belisca um pouco de reiatsu.
    pose(nome, opções)scan (lente sobre o olho), paused (selo de pausa) ou alert (susto). pose(null) limpa.
    hide() show() reset()Esconde, mostra e recomeça.
    getState() restore(estado)Quem guarda é você: o estado sai e volta como JSON.
