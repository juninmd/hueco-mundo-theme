01 · Paleta

Osso, vazio e o vermelho do Cero.

Os 13 tokens têm os nomes do Canto, então o bloco substitui a skin hueco-mundo de lá sem mexer em mais nada. O verde #4ade80, a marca do Canto, virou o reiatsu que o pet come. Clique numa cor para copiar.

O deserto, em degradê

céu--hm-sky-0 … 2
areia--hm-sand-lo … hi
cero--hm-cero-deep … core
reiatsu--hm-reishi

Extras --hm-sky-*, --hm-sand-* e --hm-cero-* para fundos, cenas e brilhos.

    import { Reiatsu, type Alma } from "./hueco-mundo";

/** Um Hollow de estimação que vive no canto da tela. */
export class Hollowzinho {
  readonly nome = "Hollowzinho";
  private reiatsu = 80; // 0 a 100

  alimentar(alma: Alma): void {
    this.reiatsu = Math.min(100, this.reiatsu + alma.valor);
    console.log(`Nham! Reiatsu em ${this.reiatsu}%`);
  }

  async cero(alvo: HTMLElement): Promise<boolean> {
    if (this.reiatsu < 12) throw new Error("Sem reiatsu pra isso");
    this.reiatsu -= 12;
    await alvo.animate([{ opacity: 1 }, { opacity: 0 }], 600).finished;
    return true;
  }
}

    05 · Hollowzinho

    Um Hollow de estimação no cantinho.

    Ele já está aí no canto da tela, olhando o seu cursor. É um web component sem dependências: <hollow-pet>. Passe o mouse para abrir a bandeja.

    Como brincar

    • clique
      Carinhocoração, vínculo +1 e um sorriso
    • segure
      Carregar o Cerosolte para disparar na direção do centro
    • C
      Mirarescolha qualquer ponto da tela como alvo
    • arraste
      Trocar de cantoele se encaixa no canto mais próximo
    • F
      Alimentarreiatsu verde; com vínculo ele evolui
    • S
      Dormirsozinho, depois de um tempo parado

    Sem eventos ainda. Faça um carinho.

    06 · Instalar

    Quatro jeitos, nenhum build.

    Em qualquer página

    <link rel="stylesheet" href="src/fonts.css">
<link rel="stylesheet" href="src/hueco-mundo.css">

<body class="hueco-mundo">

    Pet no cantinho

    <script src="src/hollow-pet.js"></script>
<hollow-pet corner="br"></hollow-pet>

    Atributos: corner size name lang tint shake

    Skin do Canto

    /* src/styles.css do canto-widget */
@import "hueco-mundo-theme/src/tokens.css";

/* depois, nos Ajustes → Aparência: */
localStorage.setItem("canto.skin", "hueco-mundo")

    VS Code

    cp -r vscode ~/.vscode/extensions/hueco-mundo
# reinicie e escolha: Preferências → Tema de Cores
